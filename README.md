# NSIS Techno Solutions

Corporate website for NSIS Techno Solutions, Visakhapatnam.

## Run

```bash
cd C:\Users\Ganesh\dynamic-website
npm install
npm run dev
```

Open http://localhost:5173

## Production

```bash
npm run build
npm start
```

Open http://localhost:3001

Admin remains at `/admin` (username `admin`).
